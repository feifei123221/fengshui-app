# 风水大师 - 专业风水应用

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

> 传承千年文化智慧，解读天地玄机，为您提供专业的风水服务

## ✨ 功能介绍

### 🔮 核心功能

1. **风水罗盘** - 专业风水罗盘，支持旋转，显示方位、五行、卦象
2. **八字算命** - 根据出生年月日时，测算生辰八字、五行属性
3. **八宅风水** - 分析房屋坐山朝向，吉凶方位布局建议
4. **二十四山向** - 详细解读24山向风水含义
5. **家居风水** - 大门、客厅、卧室、厨房、卫生间风水宜忌
6. **办公风水** - 办公桌、办公室布局、装饰风水建议
7. **黄历择吉** - 查看每日宜忌、择吉日行事
8. **吉祥物指南** - 招财、事业、健康、感情、化煞吉祥物推荐
9. **风水知识库** - 风水基础理论知识学习

## 🎯 特色

- 🎨 精美的深色主题UI，符合传统文化风格

## 🚀 快速开始

### 直接使用

1. 下载或克隆此项目
2. 直接用浏览器打开 `index.html` 即可使用

### 本地预览 (需要Python)

```bash
cd fengshui-app
python -m http.server 8000
```

然后在浏览器访问：`http://localhost:8000`

## 🔧 部署上线

### 方式一：Netlify (最简单)
1. 访问 https://app.netlify.com
2. 注册账号
3. 直接拖拽 `fengshui-app` 文件夹上传
4. 等待几秒钟，网站就上线了！

### 方式二：Vercel
1. 访问 https://vercel.com
2. 注册账号
3. 导入项目或拖拽上传
4. 一键部署

### 方式三：GitHub Pages
1. 创建GitHub仓库
2. 上传所有文件
3. 在 Settings > Pages 中开启
4. 网站地址：`https://你的用户名.github.io/fengshui-app/`

## 📊 访问统计

### Google Analytics
1. 访问 https://analytics.google.com 注册
2. 创建新的媒体资源
3. 获取 Measurement ID (格式: G-XXXXXXXXXX)
4. 替换 `index.html` 中的 `GA_MEASUREMENT_ID` 为您的ID

### 百度统计
1. 访问 https://tongji.baidu.com 注册
2. 添加网站
3. 获取统计代码
4. 替换相应的统计脚本

## 🎨 自定义

### 修改配色
